本文记录博客从 2026 年 2 月创建至今的所有重要功能更新，按时间倒序排列。

## 2026.9.4 — 移动端主题切换过渡优化

- 修复移动端切换深浅主题时瞬间只剩纯色、文字消失的闪烁问题（View Transitions 快照在触屏设备上丢失文字栅格）
- 触屏设备改用颜色过渡方案：切换时文字/边框/背景平滑变色，文字全程可见
- 桌面端保留圆形揭示动画不变；减弱动态效果（prefers-reduced-motion）用户仍为直接切换

## 2026.8.23 — 安全加固、性能瘦身与代码质量清零

- 后台安全加固：登录态改为由密码派生的会话凭据（手改浏览器标记不再能绕过登录）；密码连错 5 次锁定 1~16 分钟；自定义 GitHub API 端点需 https 公网地址且首次使用需二次确认；封面图缓存读取补齐路径越界校验
- 密码哈希强度偏低时后台自动提示改密升级；GitHub 连接页新增细粒度 Token 使用建议
- 新增图片批量瘦身脚本 `script/optimize-images.js`（超 300KB/1920px 自动转 WebP 并同步更新文章引用，幂等可重复运行）
- 性能：粒子背景库改为按需动态加载（不再全站预载约 3.6MB）；全文搜索索引改为首次打开搜索面板时才下载
- 修复：搜索组件首次加载失败后永久失效、空的自定义指令导致整站构建崩溃、新建文章标题含空格生成非法文件头、切换文章后评论区主题不同步、搜索防抖跨页污染、无痕模式下字号/主题调节报错、Windows 下绝对路径封面图识别失败、移动端剧透块连点监听堆积、热力图提示监听泄漏等 12 处问题
- 工程化：ESLint 接入 TypeScript 解析器（历史遗留的 88 个 lint 错误清零）；astro check 类型错误从 356 清零；新增统一生命周期清理器，页面切换后事件监听不再无限累积

## 2026.8.19 — 分享、RSS 与多平台同步

- 新增 RSS 订阅功能（`/rss.xml`），零新依赖，页脚与 Layout head 均已接入自动发现
- 文章页新增「复制链接」分享按钮，自动适配 clipboard API 与降级方案
- 页面接入 Open Graph / Twitter Card 分享卡片预览，社交媒体分享展示标题、描述与封面
- Giscus 评论区增加加载中与加载失败提示，加载失败时支持一键重新加载
- 搜索无结果时增加引导文案与「浏览全部归档」入口
- 归档页「标签/分类」混用文案统一为「归档」

## 2026.8.18 — 自定义样式与移动端 FAB

- 新增 8 个自定义样式工具栏按钮：下划线、模糊、彩虹、拼音、脚注、引用卡片、音乐卡片、GitHub 卡片
- 脚注自动选取未占用编号并在文末补全定义
- 新增 MobileFab 移动端浮动按钮，带阅读进度环，可展开菜单、目录、返回、评论、回顶
- 预览窗新增自定义语法预处理，支持引用卡片、提示框、推导容器、音乐/GitHub 卡片
- 新增脚注引用与文末定义列表渲染
- 文学引用由 `>` 语法统一替换为 `:::quote` 语法
- 增大后台编辑窗口大小

## 2026.8.9 — 开源与站点设置
