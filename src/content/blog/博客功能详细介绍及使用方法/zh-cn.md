这是一份详尽的博客功能说明文档，涵盖前台阅读体验、后台管理系统、以及各类特色功能的使用方法。

## 一、前台功能概览

### 1.1 首页

首页是博客的门面，包含以下元素：

- **文章列表**：以卡片形式展示所有文章，每张卡片包含封面图（或自动生成的装饰占位图）、标题、摘要、分类标签、发布日期和阅读时长
- **置顶文章**：标记了置顶的文章会显示金色圆点和 📌 标记，排列在列表最前
- **打字机签名**：首页顶部有一段循环播放的打字机动画，展示个性化签名
- **粒子背景**：基于 tsParticles 的暖棕色粒子动画，首页、文章页、归档页有不同的粒子密度和交互效果，移动端自动关闭以节省性能
- **更新提示**：当有新文章发布或旧文章更新时，首页会弹出一次性通知，点击可直达最新文章

### 1.2 文章阅读页

点击文章卡片进入阅读页，包含：

- **面包屑导航**：显示「首页 > 大分类 > 小分类 > 文章标题」的路径，可点击跳转
- **文章元信息**：标题、发布日期、最后更新日期、阅读时长和字数统计
- **封面图**：支持用户上传的封面图，或通过 Pexels API 根据标题/分类自动获取的封面图
- **正文内容**：支持 Markdown 渲染，包含自定义样式语法（详见第三篇文章）
- **公式推导浮层**：数理公式支持 hover（移动端点击）弹出推导过程，不打断阅读节奏
- **图片灯箱**：点击任意图片进入全屏预览，支持滚轮/手势缩放、拖拽平移、多图切换
- **版权卡片**：文章末尾显示 CC BY-NC-SA 4.0 许可协议
- **同分类推荐**：文末推荐同一分类下的其他文章
- **评论区**：基于 Giscus 的评论系统，使用 GitHub 账号登录后即可在网页评论
- **返回按钮**：右侧悬浮的返回上一页按钮

### 1.3 归档页

归档页以时间轴形式展示所有文章：

- 按年/月两级折叠，点击展开或收起
- 每篇文章显示标题、日期、分类标签（按分类着色）和阅读时长
- 支持分类筛选，点击分类标签可过滤文章

### 1.4 关于页

关于页包含个人信息展示：

- **个人介绍**：自我描述文字
- **MBTI / 专业 / 最近在做 / 最近在读**：个人档案信息
- **旅行地图**：基于 ECharts + GeoJSON 的交互式中国地图，标注已访问的城市
- **音乐播放器**：嵌入网易云音乐播放器
- **站点时间轴**：博客开发历程记录

### 1.5 工具栏页

工具栏页整合了常用工具链接，包括真值表生成器、计算器、GitHub、Gitee、Markdown 预览等。

### 1.6 404 页面

访问不存在的页面时，显示 404 页面并推荐最新的 4 篇文章。

## 二、交互功能详解

### 2.1 主题切换

- 点击导航栏的太阳/月亮图标切换亮色/暗色主题
- 自动记忆用户偏好（localStorage）
- 首次访问时跟随系统偏好
- 切换时有圆形揭示过渡动画

### 2.2 全局搜索

- 快捷键 `/` 或 `Ctrl/Cmd + K` 唤起搜索面板
- 基于 Pagefind 的静态全文搜索，支持标题与正文关键词检索
- 包含搜索历史与热门推荐

### 2.3 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `j` | 跳转到下一篇文��� |
| `k` | 跳转到上一篇文章 |
| `g` 然后 `h` | 返回首页 |
| `/` | 唤起搜索 |

### 2.4 沉浸阅读模式

- 双击正文进入全屏阅读模式，隐藏导航栏和侧边栏
- 再次双击退出全屏
- 支持正文字号调节（右侧浮动按钮）

### 2.5 移动端适配

- **底部导航栏**：首页、归档、关于、工具栏四个快捷入口
- **MobileFab 浮动按钮**：右上角的收拢式浮动按钮，带阅读进度环，点击展开菜单、目录、返回上一页、评论、回顶
- **侧边抽屉**：包含搜索、主题切换、新手指南、邮箱复制、字体调节等快捷操作

### 2.6 图片灯箱

- 点击文章中的图片进入全屏预览
- 支持滚轮缩放、双击缩放、手势缩放（移动端）
- 支持拖拽平移
- 多图时可左右切换
- 键盘方向键切换图片，`+`/`-` 缩放，`Esc` 关闭

### 2.7 公式推导浮层

- 数理公式下方有虚线下划线，表示可查看推导过程
- 桌面端 hover 弹出推导浮层
- 移动端点击弹出
- 浮层内支持公式渲染和滚动

## 三、后台管理系统

访问 `/admin` 进入后台管理系统。首次使用无需密码，直接进入；后续可在安全设置中设置密码。

### 3.1 GitHub 连接

后台通过 GitHub API 直接操作仓库中的文件，需要配置：

1. **GitHub Token**：在 [GitHub Settings > Developer settings > Personal access tokens](https://github.com/settings/tokens) 生成，需要 `repo` 权限
2. **仓库信息**：自动读取配置文件中的仓库所有者和仓库名
3. **分支**：默认为 `main`

填写 Token 后点击「连接」，成功后即可使用所有后台功能。

### 3.2 文章管理

文章管理采用三栏布局：文章列表 + 编辑器 + 实时预览。

**文章列表**：
- 加载后显示所有文章的标题、日期、分类、语言和置顶状态
- 支持搜索过滤
- 单击选中，双击或 Enter 载入编辑器
- 置顶文章显示 📌 标记

**编辑器**：
- **元数据区**：标题、slug（URL 友好标识）、语言、发布日期、摘要、封面路径、大分类、小分类、置顶开关
- **工具栏**：提供丰富的 Markdown 格式插入按钮（详见下文）
- **正文区**：Markdown 编辑区域，支持自动保存草稿（刷新可恢复）
- **上传区**：支持上传图片/文件/PDF，自动转换为 Markdown 引用语法

**工具栏按钮详解**：

| 按钮 | 功能 | 语法 |
|------|------|------|
| B | 粗体 | `**文本**` |
| I | 斜体 | `*文本*` |
| S | 删除线 | `~~文本~~` |
| H2 / H3 | 标题 | `## / ###` |
| 🔗 | 链接 | `[文本](URL)` |
| { } | 行内代码 | `` `code` `` |
| <> | 代码块 | ` ```lang ``` ` |
| ƒ | 行内公式 | `$公式$` |
| ∑ | 块级公式 | `$$公式$$` |
| 推导 | 推导容器 | `:::derivation ... :::` |
| U | 下划线 | `++文本++` |
| 模糊 | 剧透文本 | `!!文本!!` |
| 彩虹 | 彩虹文字 | `==文本==` |
| 拼音 | 注音标注 | `{汉字}(拼音)` |
| 脚注 | 脚注 | `[^N]` + 文末定义 |
| 引卡 | 引用卡片 | `:::quote ... :::` |
| 音乐 | 音乐卡片 | `::music{id="..."}` |
| GH | GitHub 卡片 | `::github{repo="..."}` |

**实时预览**：
- 右侧预览区实时渲染 Markdown 内容
- 支持源码/预览视图切换
- 支持编辑器与预览区的选中文字同步高亮
- 预览区支持自定义语法渲染（引用卡片、提示框、脚注等）

**发布流程**：
1. 填写元数据和正文
2. 点击「发布」按钮
3. 后台自动创建/更新 `src/content/blog/{slug}/zh-cn.md` 文件
4. GitHub Actions 自动部署到 GitHub Pages

### 3.3 站点设置

站点设置包含 8 个子面板：

| 面板 | 功能 |
|------|------|
| 站点信息 | 编辑站点标题、标语、创建时间 |
| 首页签名 | 编辑首页打字机动画的签名内容 |
| 联系方式 | 编辑 GitHub URL 和邮箱地址 |
| 关于-介绍 | 编辑关于页的 Markdown 介绍文字 |
| 关于-个人 | 编辑个人简介、音乐列表、旅行城市 |
| 关于-档案 | 编辑 MBTI、专业、最近在做/读 |
| 工具链接 | 编辑工具栏页的链接列表 |
| 时间线 | 编辑站点开发时间轴（日期\|内容格式） |
| 博客指南 | 编辑新手指南弹窗的内容 |

每个面板都有独立的保存按钮，修改后点击保存即可通过 GitHub API 更新对应的数据文件。

### 3.4 安全设置

- 可设置/修改后台登录密码
- 密码使用 PBKDF2-SHA256 哈希存储
- 未设置密码时可直接进入后台

### 3.5 导出功能

支持将博客导出为 ZIP 文件，包含所有文章和资源文件。

## 四、技术架构

- **框架**：Astro 5.x（静态站点生成）
- **样式**：Tailwind CSS v4 + CSS 自定义属性
- **搜索**：Pagefind（静态全文搜索）
- **评论**：Giscus（GitHub Discussions）
- **地图**：ECharts + GeoJSON
- **粒子**：tsParticles
- **数学公式**：KaTeX
- **代码高亮**：highlight.js
- **部署**：GitHub Actions → GitHub Pages
